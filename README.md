# Debian

Script para gestión, auditoría y mantenimiento de sistemas Debian.

## Scripts de Mantenimiento y Rendimiento

### actualizar_mint.sh
Script para actualizar un sistema operativo Linux Mint.

### actualizar_sistema.sh
Script para actualizar un sistema Debian.

### ajustar_hora_y_zona_completo.sh
Script para ajustar la hora y zona horaria del sistema.

### aumentar_swap.sh
Script para aumentar el tamaño de la memoria de intercambio (swap).

### check_memory.sh
Script para verificar el uso de la memoria RAM.

### liberar_memoria.sh
Script para liberar la memoria caché y de intercambio.

### limpiar_swap.sh
Script para limpiar la memoria de intercambio.

### mantenimiento.sh
Script para realizar tareas de mantenimiento general en el sistema.

### monitor.sh
Monitor de sistema en tiempo real para auditar el rendimiento.

### monitor_temperatura.sh
Script para monitorear la temperatura de la CPU.

### optimizar_cpu.sh
Script para optimizar el uso de la CPU.

### ram_swap.sh
Script para auditar el uso de RAM y swap.

### ranking.sh
Script para crear un ranking de los usuarios por su nivel.

## Scripts de Auditoría

### auditar_almacenamiento.sh
Script para auditar el uso del disco y los directorios más grandes.

### auditar_apps.sh
Script para auditar las aplicaciones instaladas en el sistema.

### auditar_configuracion.sh
Script para auditar la seguridad de los archivos de configuración.

### auditar_controladores.sh
Script para auditar los controladores y módulos del kernel cargados.

### auditar_impresoras.sh
Script para auditar las impresoras locales y de red.

### auditar_logs.sh
Script para auditar la existencia de archivos de registro del sistema.

### auditar_procesos.sh
Script para auditar los procesos que consumen más CPU y memoria.

### auditar_puertos.sh
Script para auditar los puertos de red abiertos.

### auditar_redes.sh
Script para auditar las conexiones de red existentes.

### auditar_usuarios.sh
Script para auditar los usuarios y sus permisos en el sistema.

### auditar_usuarios_bd.sh
Script para auditar usuarios y permisos en bases de datos.
